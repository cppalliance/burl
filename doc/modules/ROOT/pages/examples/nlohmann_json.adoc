= nlohmann/json

A complete, runnable example of teaching Burl a body type it has never heard of,
extracted from `example/nlohmann_json.cpp`. It puts
xref:2.guide/2n.extending.adoc[Extending] to work on
https://github.com/nlohmann/json[`nlohmann::json`^]: a pair of `tag_invoke`
overloads, found by argument-dependent lookup, that make the type a first-class
body in both directions.

== Sending: body_from_tag

The cpp:body_from_tag<T>[] overload serializes the document up front with
`dump()`, so the body owns the text and reports a known `Content-Length`.

[source,cpp]
----
include::example$nlohmann_json.cpp[tag=body_from,indent=0]
----

See xref:2.guide/2n.extending.adoc[].

== Receiving: body_to_tag

The cpp:body_to_tag<T>[] overload reads the body and parses it, following the
recommended cpp:response::try_as_view[try_as_view] pattern: in place when the
body fits the parser's buffer, falling back to a cpp:std::string[] on overflow.

[source,cpp]
----
include::example$nlohmann_json.cpp[tag=body_to,indent=0]
----

See xref:2.guide/2n.extending.adoc[].

== Using It

With both overloads in place, `nlohmann::json` is just another body type: the
same cpp:request_builder::body[body] and cpp:request_builder::as<T>[as<T>] calls
that drive the built-ins now work on it unchanged:

[source,cpp]
----
include::example$nlohmann_json.cpp[tag=round_trip,indent=0]
----

When the value is a literal, you can name the type on
cpp:request_builder::body[body<T>] to construct it inline:

[source,cpp]
----
include::example$nlohmann_json.cpp[tag=round_trip_inline,indent=0]
----
